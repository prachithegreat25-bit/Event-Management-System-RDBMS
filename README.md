## 📌 Project Overview
The **Event Management System** is a normalized relational database application designed to manage venues, organizers, events, participant registrations, sponsorships, and post-event feedback. It is built using MySQL and follows strict ACID properties, Third Normal Form (3NF) relational design, and dynamic PL/SQL triggers.

---

## 🛠️ Tech Stack & Concepts Covered
* **Database:** MySQL / MySQL Workbench
* **Database Concepts:** 
  * ER Diagrams & 3NF Schema Normalization
  * Data Definition Language (DDL) & Data Manipulation Language (DML)
  * Multi-table JOINs, Nested Subqueries, Aggregate Functions
  * Views & Performance Indexing
  * Triggers & Capacity Control Mechanics
